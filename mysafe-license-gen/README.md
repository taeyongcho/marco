# MySafe License Generator

**IT Brain Co., Ltd. 내부 전용** · MySafe 라이선스 키 발급 프로그램

이 프로그램에는 라이선스 서명용 **Ed25519 비밀키**가 포함되어 있습니다. 고객이나 외부에 배포하지 마세요.

## 사용법

1. 실행 후 비밀번호로 로그인합니다. 최초 비밀번호는 `itbrain`이며, 첫 로그인 후 「비밀번호 변경」으로 반드시 바꾸세요.
2. **사용자명**을 입력합니다. 고객이 MySafe에 등록할 때 이 이름을 그대로 입력해야 합니다. (대소문자와 연속 공백 차이는 무시됩니다.)
3. 라이선스 종류를 고릅니다.
   - **체험판** : 발급일로부터 1개월. 만료일을 직접 지정할 수도 있습니다.
   - **영구** : 기간 제한 없음.
4. 「라이선스 키 생성」을 누르고, 사용자명과 키를 고객에게 전달합니다. 텍스트 파일로 저장할 수도 있습니다.

발급 이력은 이 PC에만 저장됩니다 (`%APPDATA%\MySafe License Generator\history.json`).

## 키 구조

| 항목 | 내용 |
|---|---|
| 서명 | Ed25519 (비밀키는 발급기, 공개키는 MySafe 앱에 포함) |
| 서명 대상 | `MySafe\|v1\|<정규화한 사용자명>\|<종류>\|<만료일수>` |
| 인코딩 | Base32, 6자씩 하이픈으로 구분 |
| 종류 | 0 = 영구, 1 = 체험판 |

키를 고쳐 쓰거나 다른 사용자명으로 쓰면 서명 검증에서 걸러집니다.

## 빌드

```bash
npm install
npm start            # 개발 모드
npm test             # 키 생성/검증, 비밀번호 해시 테스트
npm run dist:win     # 단일 실행 파일 → dist/MySafe-LicenseGen-1.0.0.exe (설치 불필요)
```
