# MySafe

**Made by IT Brain Co., Ltd.**

SplashID 스타일의 **로컬 비밀번호 관리자** (Windows용). Electron으로 만들어졌으며 모든 데이터는 내 PC 안에만 암호화되어 저장됩니다.

## 기능

- **마스터 비밀번호 잠금** : 하나의 마스터 비밀번호로 전체 볼트를 잠그고 풉니다.
- **주메뉴(기본 5종)** 와 각 주메뉴의 입력 항목
  | 주메뉴 | 항목 |
  |---|---|
  | 시스템로그인 | ID / Pass / e-Mail / URL / IP / Memo |
  | 뱅킹 | 은행명 / 예금주 / 계좌번호 / ID / Pass / URL / 자동이체 리스트 / Memo |
  | 크레디트카드 | 카드명 / 카드번호 / 만료일(달력) / PIN / 카드비번 / 결제은행 / 결제계좌 / 결제일 / URL / ID / Pass(로그인) / Memo |
  | 보험 | 보험사 / 피보험자 / 보험상품 / URL / 만기일 / 자동이체은행·카드 / 자동이체계좌·카드번호 / 결제일 / 보험료 / Memo |
  | 기념일 | 구분 / 관계 / 양·음 / 띠 / 생년월일 / Memo |
- **주메뉴별 카테고리** : 보험은 개인·배우자·자녀·가족, 기념일은 가족·친구·업무가 기본이며 Edit 창에서 주메뉴마다 따로 정할 수 있습니다. 비워 두면 공용 카테고리를 씁니다.
- **기념일 편의 기능** : 생년월일을 넣으면 요일이 함께 표시되고 띠가 자동으로 채워집니다(직접 바꿀 수 있음). 양·음 구분이 날짜 위에 있어 먼저 고르고 입력합니다.
- **제목 자동 생성** : 보험처럼 제목이 따로 필요 없는 주메뉴는 제목칸을 숨기고 보험사·보험상품으로 제목을 만듭니다.
- **D-day와 일정 알림** : 만기일(1회)·기념일(매년) 형식의 항목에 D-day 표시, 「다가오는 일정」 보기와 사이드바 배지, 잠금 해제 시 토스트와 Windows 알림 (기준 일수 설정 가능)
- **화면** : 밝게/어둡게/시스템 테마, 글꼴 크기 4단계, 목록 표시 방식(간단히/자세히), 정렬(이름·최근 수정·최근 추가·즐겨찾기 우선·D-day)
- **볼트 파일 위치 지정** : USB나 OneDrive·Google Drive 같은 동기화 폴더로 이동, 다른 PC에서 「기존 볼트 파일 열기」로 연결, 기본 위치로 되돌리기
- **Edit(주메뉴 편집)** : 주메뉴를 자유롭게 추가·이름 변경·삭제하고, 각 주메뉴의 항목을 추가·삭제·순서 변경. 주메뉴 순서 변경. 항목 형식은 일반 / 비밀(가림) / URL / 날짜(1회, D-day) / 기념일(매년, D-day) / 선택(드롭다운) 중 선택
- **카테고리 / 즐겨찾기 / 최근 수정** 으로 분류하고, 제목·아이디·주소·메모를 즉시 검색
- **비밀번호 가리기·보기·복사** : 복사한 값은 설정한 시간(기본 30초) 뒤 클립보드에서 자동 삭제
- **비밀번호 생성기** : 길이, 대·소문자, 숫자, 특수문자, 혼동 문자 제외 옵션
- **라이선스** : 체험판(1개월)과 영구 라이선스. 시스템 날짜를 뒤로 돌리면 감지해 잠급니다. 사용자명 + 키로 등록하며 앱 이름 옆에 사용자명이 표시됩니다. 라이선스가 없거나 만료되면 잠금 해제가 막히고 재등록을 요구합니다(저장된 데이터는 그대로 보존)
- **자동 잠금** : 마지막 조작 이후 일정 시간(기본 5분) 아무 입력이 없으면 잠김. 타이핑·마우스·스크롤 등 조작이 있으면 카운트가 처음부터 다시 시작되고, 편집 중이라도 시간이 되면 반드시 잠깁니다(작성 중이던 내용은 잠금 해제 후 복원)
- **마스터 비밀번호 변경**, **CSV 내보내기/가져오기**(백업·이전용)
- 단축키 : `Ctrl+N` 새 항목, `Ctrl+F` 검색, `Ctrl+S` 저장, `Ctrl+L` 잠금, `Esc` 편집 취소

## 보안 구조

| 항목 | 내용 |
|---|---|
| 키 유도 | scrypt (N=2^15, r=8, p=1), 16바이트 랜덤 salt |
| 암호화 | AES‑256‑GCM (무결성 검증 포함) |
| 라이선스 | Ed25519 전자서명, 앱에는 공개키만 포함 (발급은 IT Brain Co., Ltd. 발급기 전용) |
| 날짜 되돌림 감지 | 마지막 사용 시각을 HMAC 서명해 설정 파일·상태 파일·볼트 안 세 곳에 기록하고, 그보다 10분 이상 뒤로 간 시각을 거부 |
| 저장 위치 | 기본 `%APPDATA%\MySafe\vault.mv` (설정에서 변경 가능, 위치는 `config.json`에 기록) |
| 메모리 | 잠금 시 키를 0으로 덮어쓰고 폐기 |
| 렌더러 격리 | contextIsolation + sandbox, Node 접근 불가, IPC로만 통신 |

마스터 비밀번호를 잊으면 **복구할 방법이 없습니다.**

## 설치 (Windows)

1. `MySafe-Setup-1.0.0.exe` 를 실행합니다.
2. 설치 폴더를 고른 뒤 설치하면 바탕화면과 시작 메뉴에 바로가기가 생깁니다.
3. 첫 실행에서 마스터 비밀번호(8자 이상)를 만들면 바로 사용할 수 있습니다.

> 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 뜰 수 있습니다. 「추가 정보 → 실행」을 누르면 됩니다.

## 개발 / 빌드

```bash
cd mysafe
npm install          # Electron + electron-builder 설치
npm start            # 개발 모드 실행
npm test             # 암호화·CSV 단위 테스트
npm run dist:win     # Windows 설치 파일 생성 → dist/MySafe-Setup-<버전>.exe
```

Windows PC에서 그대로 빌드됩니다. Linux/macOS에서 Windows 설치 파일을 만들려면 `wine`(32비트 포함)이 필요합니다.

## 폴더 구조

```
mysafe/
├─ src/
│  ├─ main.js      # Electron 메인 프로세스, IPC, 클립보드, 파일 대화상자
│  ├─ preload.js   # 렌더러에 노출하는 안전한 API
│  ├─ vault.js     # scrypt + AES-256-GCM 볼트 파일 암호화/복호화
│  └─ csv.js       # CSV 내보내기/가져오기
├─ renderer/       # 화면 (index.html, style.css, app.js)
├─ test/           # node:test 단위 테스트
└─ build/          # 앱 아이콘 (icon.svg 원본 → icon.ico/icon.png 생성)
```

## 날짜 되돌림 감지

체험판 만료를 피하려고 PC 날짜를 과거로 돌리는 것을 막습니다.

- 앱을 쓸 때마다 "지금까지 본 가장 늦은 시각"을 HMAC으로 서명해 **설정 파일**, **별도 상태 파일**, **암호화된 볼트 파일** 세 곳에 기록합니다.
- 현재 시각이 그보다 10분 넘게 뒤라면 잠금 해제를 막고 날짜를 맞추라고 안내합니다. 10분 이내 오차(시각 동기화 등)는 정상으로 봅니다.
- 기록을 손으로 고치거나 다른 PC의 기록을 복사해 오면 서명이 맞지 않아 변조로 처리합니다.
- 만료 판정은 항상 "본 적 있는 가장 늦은 날짜" 기준이라, 날짜를 되돌려도 만료된 체험판은 계속 만료 상태입니다.
- 사용 중에도 10분마다 다시 확인하며, 되돌리면 즉시 잠깁니다.
- 어느 경우든 **저장된 데이터는 손대지 않습니다.** 날짜를 바로잡고 「다시 확인」을 누르면 그대로 쓸 수 있습니다.

## 라이선스 발급 (IT Brain Co., Ltd. 내부용)

`../mysafe-license-gen` 폴더의 **MySafe License Generator**로 발급합니다.

```bash
cd mysafe-license-gen
npm install
npm start            # 개발 모드 (기본 비밀번호: itbrain, 첫 로그인 후 변경 권장)
npm run dist:win     # 단일 실행 파일 → dist/MySafe-LicenseGen-1.0.0.exe
```

1. 발급기를 실행하고 비밀번호로 로그인합니다.
2. 사용자명을 입력하고 **체험판(1개월)** 또는 **영구**를 고른 뒤 키를 생성합니다.
3. 사용자명과 키를 고객에게 전달하면, 고객은 MySafe 잠금 화면의 「라이선스 등록」에 입력합니다.

발급기에는 서명용 **비밀키**가 들어 있습니다. 고객에게 배포하지 마세요.

## 볼트 파일을 잃지 않으려면

- **위치를 옮겨도 원본은 남습니다.** 설정에서 볼트를 다른 폴더로 옮기면 이전 위치의 파일을 지우지 않고 `vault.mv.moved-<시각>.bak`으로 남겨 둡니다. 옮긴 폴더가 사라져도 되찾을 수 있습니다. 사본을 남기고 싶지 않으면 설정 → 백업에서 지울 수 있습니다.
- **자동 백업.** 잠금을 풀 때 하루 한 번, 볼트를 `%APPDATA%\MySafe\backups`에도 복사합니다. 최근 10개를 보관하므로 볼트를 둔 폴더가 통째로 사라져도 남습니다.
- **사라지면 되살릴 목록을 보여 줍니다.** 지정한 위치에 볼트가 없으면 기본 위치·이전 위치·백업 폴더를 뒤져 후보를 날짜순으로 보여 주고, 고르면 그대로 이어서 씁니다. 예전 볼트가 남아 있는 한 빈 볼트를 새로 만드는 화면으로 넘어가지 않습니다.
- **설치 폴더에는 둘 수 없습니다.** 프로그램 설치 폴더나 임시 폴더를 저장 위치로 고르면 거부합니다. 업데이트 설치는 설치 폴더를 통째로 지우고 다시 만들기 때문입니다(`RMDir /r $INSTDIR`).
- **이미 설치 폴더에 둔 경우에도 안전합니다.** 설치 프로그램이 설치 전에 볼트 파일을 임시 보관했다가 설치가 끝나면 제자리에 되돌리고, `%APPDATA%\MySafe\backups`에도 한 부 남깁니다. 앱을 켜면 설치 폴더에 있는 볼트를 기본 위치로 자동으로 옮기고 알려 줍니다.
- USB나 클라우드 동기화 폴더에 두었다면, 그 드라이브가 연결되어 있을 때만 잠금을 풀 수 있습니다.

## 기존 데이터

버전을 올려도 저장된 내용은 지워지지 않습니다. 새 구성으로 올릴 때 볼트 파일을 `vault.mv.<날짜>.bak`으로 한 번 복사해 두고, 주메뉴 정의만 갱신합니다. 항목에 입력한 값은 그대로 남으며, 크레디트카드 만료일처럼 형식이 바뀐 항목은 기존 표기(`12/28`)를 날짜 형식(`2028-12-31`)으로 옮겨 적습니다.
